# CSS Zen Garden — modern edition

Side Project: **CSS Zen Garden** by **David Shea**. All credits for David Shea.

A static, build-less re-implementation of [csszengarden.com](https://github.com/mezzoblue/csszengarden.com):
the HTML never changes, only the external CSS does.

- **Themes**: 30 original designs (credited to their authors), instant switching, prev/next, random, gallery, `Shift+←/→`.
- **i18n**: en, es, pt-BR, fr, de, nl, ru, zh-CN, zh-TW (auto-detected, `?lang=es`).
- **Responsive** + desktop **mobile-preview float** (iframe, `?embed=1`).
- Vanilla ES modules, Custom Elements + Shadow DOM, View Transitions. No build step.
- Deep links: `?theme=003&lang=pt-br`.

Original designs and text © their authors, licensed [CC BY-NC-SA 3.0](LICENSE). Non-commercial use only.
